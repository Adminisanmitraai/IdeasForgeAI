ETA AVAILABILITY
The visible prediction line renders only when all conditions are true:

- snapshot source is runtime

- snapshot is certified
- Phase 2 etaAvailable is true
- runtime analytics is not stale
- prediction is not stalled
- prediction is not insufficient
- trend direction is advancing
- duration formatting is valid

- velocity formatting is valid
- confidence formatting is valid

ETA SUPPRESSION
No visible prediction line renders for:

- etaAvailable = false
- stale runtime data
- stalled progress
- insufficient data
- stable trend
- regressing trend
- invalid/non-finite duration
- invalid completion timestamp
- invalid/non-finite velocity
- fallback source
- uncertified snapshot

Unavailable prediction never displays a fabricated date, zero duration,
Infinity, NaN, or raw milliseconds.

An accessible title provides a compact unavailable reason:

- progress data is stale
- progress is stalled
- more progress history is needed
- progress is stable
- progress is regressing
- an estimate is not available

DURATION FORMATTING
The component formats the existing Phase 2 duration without recomputing ETA:

- below 60 seconds: under 1 minute
- below 1 hour: rounded-up whole minutes
- below 1 day: hours plus remaining minutes
- 1 day or more: days plus remaining hours

Verified examples:

- under 1 minute
- 12 minutes
- 2 hours 15 minutes
- 1 day 4 hours

Raw milliseconds remain semantic data only and are never visible text.

COMPLETION-TIME FORMATTING
- Reads estimatedCompletionTime from the Phase 2 prediction.
- Validates it through Date before display.
- Uses the user's local date/time formatting.
- Invalid timestamps suppress the visible prediction line.
- No milestone date is invented.

VELOCITY FORMATTING
- Reads progressVelocityPerHour from Phase 2.
- Requires a finite value greater than zero.
- Displays one decimal place:
  +1.2% per hour
- Does not display excessive precision.

- unavailable/unknown -> no visible prediction line
