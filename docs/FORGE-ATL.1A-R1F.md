# FORGE-ATL.1A-R1F — Isolated Training Cockpit UI Shell

Static cockpit shell bound only to certified-style fixtures. It exposes the School Dashboard and nine Student hash routes with Classroom, Examination, Mastery, Failure Analysis, Timeline and Replay/Audit panels.

All Students intentionally render IDLE because this milestone has no live event source. Empty panels say so explicitly rather than fabricating training activity.

No network endpoint, server route, training control, GPU provider, Teacher/model call, ForgeWa runtime binding or ForgeCommander production binding is present. Visual certification is performed against a local static server in the disposable ForgeATL worktree.
