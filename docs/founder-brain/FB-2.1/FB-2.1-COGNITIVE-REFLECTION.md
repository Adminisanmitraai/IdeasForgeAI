# FB-2.1 — Cognitive Reflection & Self-Correction

Status: implemented, focused verification PASS.

## Added
- Expected-vs-actual decision reflection.
- Deterministic outcome alignment / partial / divergence classification.
- Prediction-error estimate from explicit outcome text overlap.
- Linked assumption attribution for refuted, untested, or validating assumptions.
- Evidence-backed reflection candidates requiring review.

## Governance boundary
Reflection never rewrites old decisions or assumptions. Missing outcomes fail closed. Reflection candidates remain review-required and advisory-only; no execution capability is introduced.
