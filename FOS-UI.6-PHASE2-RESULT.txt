PREDICTION ANALYTICS
The frozen FounderProgressPrediction object contains:

- progressVelocityPerHour
- remainingProgress
- etaAvailable
- estimatedCompletionTime
- estimatedRemainingDurationMs
- predictionConfidence
- stalled
- insufficientData

All unavailable velocity, duration, and timestamp values are represented as
null. No Infinity or NaN is exposed.

DETERMINISTIC INPUT RULES
- Uses only observations where certified is true.
- Reuses the existing bounded 50-observation cache.
- Deduplicates prediction evidence by completion percentage and certified
  timestamp.
- Ignores uncertified observations.
- Preserves observation arrival order.
- Requires at least two unique certified observations.
- Requires valid timestamps and positive elapsed milliseconds.
- Does not use polling time, random values, machine learning, or fabricated
  milestone dates.

DETERMINISTIC FORMULAS

1. Elapsed time

elapsedMilliseconds =
  latestCertifiedTimestamp - firstCertifiedTimestamp

The value must be finite and greater than zero.

2. Progress delta

progressDelta =
  latestCertifiedProgress - firstCertifiedProgress

3. Velocity per hour

rawVelocity =
  progressDelta / elapsedMilliseconds * 3_600_000

Only finite positive velocity is exposed.
Velocity is bounded by:

MAX_PREDICTION_VELOCITY_PER_HOUR = 100

4. Remaining progress

remainingProgress =
  clamp(100 - latestCertifiedProgress, 0, 100)

5. Estimated remaining duration

rawRemainingDurationMs =
  remainingProgress / progressVelocityPerHour * 3_600_000

The duration is rounded up to a whole millisecond and bounded by:

MAX_PREDICTION_DURATION_MS = 365 days

6. Estimated completion time

estimatedCompletionMs =
  evaluatedAtMs + estimatedRemainingDurationMs

The calculation uses the provider's injectable evaluation time.
The timestamp must be finite and within the JavaScript Date range before
conversion to ISO text.

ETA SUPPRESSION RULES
etaAvailable is false when any of these applies:

- fewer than two unique certified observations
- invalid timestamp
- zero or negative elapsed time
- stale runtime data
- stable latest certified trend
- regressing latest certified trend
- insufficient-data trend
- stalled progress
- zero or negative progress delta
- null or non-finite velocity
- remaining progress is zero
- evaluation time is non-finite
- duration or completion timestamp cannot be represented safely

Duplicate-only history remains insufficient and cannot create ETA.

STALL RULE
stalled is true only when:

- prediction history is otherwise sufficient
- the latest two unique certified timestamps are valid and increasing
- the latest two certified completion percentages are equal

A stalled result suppresses ETA.

CONFIDENCE RULES
Confidence uses unique certified prediction snapshots only:

- fewer than 2 snapshots: unavailable
- exactly 2 snapshots: low
- 3 or 4 snapshots: medium
- 5 or more snapshots: high

Duplicate and uncertified observations do not increase confidence.
