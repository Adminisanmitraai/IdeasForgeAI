TINY VELOCITY BEHAVIOR
----------------------

A single deterministic presentation threshold of 0.1 percent per hour is
defined in the velocity formatter.

- finite positive velocity below 0.1 renders as "<0.1% per hour"
- finite positive velocity at or above 0.1 renders with one decimal place
- zero, negative, NaN, and Infinity return no label and suppress prediction
- negative zero returns no label
- the underlying velocity calculation was not changed

This prevents every finite positive velocity from being presented as 0.0.

ESCAPING BEHAVIOR
-----------------

Prediction formatters now return plain, unescaped text. Prediction title text
and trend title text are composed from those raw values. Each final value is
escaped exactly once where it crosses into HTML.

The same raw formatted values feed both visible prediction content and the
accessible title. Visible dynamic values are independently escaped once at
their HTML insertion boundary.

Protection remains active for:

- ampersand
- less-than
- greater-than
- double quote
- single quote

An ampersand in locale-formatted completion text renders as "&amp;" in source,
never "&amp;amp;". Existing milestone escaping is unchanged.

PAST ETA BEHAVIOR
-----------------

One render-time timestamp is captured for each component render. Prediction
completion formatting returns no value when:

- the completion timestamp is missing
- the render timestamp is non-finite
- the completion timestamp is invalid or non-finite
- the completion timestamp is equal to render time
- the completion timestamp is earlier than render time
- local date/time formatting throws

Visible prediction also explicitly requires:

- etaAvailable=true
- finite positive remaining duration
- finite positive velocity
- certified runtime certified_manifest data
- current, advancing, non-stalled, sufficient analytics
- recognized confidence
- valid future completion formatting

Invalid analytics are not mutated, repaired, or fabricated. The prediction
group is omitted entirely when validation fails, leaving no stale accessible
prediction content.

MOBILE CLIPPING BEHAVIOR
------------------------

The existing layout and fixed mobile placement are preserved.

Hardening changes:

- prediction row has box-sizing, width, max-width, and min-width containment
- prediction label remains fixed to its compact intrinsic width
- prediction metadata can shrink with min-width: 0
- prediction metadata retains overflow: hidden and text-overflow: ellipsis
- prediction metadata explicitly remains on one line
- mobile intelligence content has min-width: 0 and overflow containment

redesign, or desktop geometry change was introduced. The health row and
